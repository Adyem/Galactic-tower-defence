# Tower Ascend — Active Skill Synergy-Class Redesign for Luna

**Status:** Active design and implementation guide. This is the document Luna should continue from. The documents under `ARCHIVED_COMPLETED_DESIGN_DOCS_DO_NOT_CONTINUE_HERE` are historical references only.

## 1. Goal

Redesign active skills so a player's five equipped skills form a recognizable playstyle. These playstyles behave like classes, but the player does not select a class from a separate menu. A class identity emerges from the skill tags, interactions, and ultimate chosen in the loadout.

The six core synergy classes are:

1. **Arcanist — hard-cast damage and field control.** Frequently cast direct attacks build resources for slower finishers.
2. **Legion Commander — summon quantity and army-wide buffs.** Wins by producing, preserving, and empowering many allied units.
3. **Bloodbinder — tower life converted into spell power.** Spends tower health for strong effects and recovers it by sacrificing summons.
4. **Usurper — enemy manipulation and infighting.** Converts enemy pressure into temporary allies, disorder, and friendly fire.
5. **Fortress Architect — walls, towers, and path control.** Turns the battlefield into a more traditional tower-defense layout.
6. **Stormcaller — elemental sequencing and chain reactions.** Applies elemental states, then casts spells in the correct order to produce escalating reactions.

Nine expansion classes are also specified later in this document: **Chronomancer**, **Bounty Hunter**, **Plaguewright**, **Salvager**, **Beastmaster**, **Artillerist**, **Void Shepherd**, **Oathkeeper**, and **Fatebinder**. They should be implemented after their shared systems are stable rather than added to one enormous first milestone.

The redesign must preserve the current five-skill bar, manually activated ultimate, deterministic replay model, Workshop node trees, content validation, and headless test workflow.

## 2. Class identity without a hard class lock

Every skill and ultimate receives one or more `synergy_group` tags. The loadout screen calculates the dominant group from the five equipped skills.

```text
1 matching skill  = an individual tool; no class bonus
2 matching skills = interaction online; show the class name as a minor affinity
3 matching skills = primary class identity; enable its central loop
4 matching skills = specialist loadout; improve consistency, not raw damage
5 matching skills = pure-class loadout; unlock a rule-changing resonance effect
```

Do not grant a generic `+X% damage per matching skill`. The reward for matching skills is that they feed one another: one skill creates a resource, state, unit, mark, or battlefield feature that another skill consumes or improves.

Mixed builds remain legal. A `3 + 2` loadout should create a primary class and a secondary package. A skill may carry a secondary tag when its behavior honestly supports two archetypes. For example, a summon can support both Legion Commander and Bloodbinder, while a sentry can support Legion Commander and Fortress Architect.

The ultimate is selected separately and does not consume a skill slot. A matching ultimate should complete the class loop, but off-class ultimates remain usable. The UI labels a matching ultimate `RESONANT` and explains the exact interaction.

## 3. Shared synergy-class rules

### 3.1 Explicit resources and states

Each class may own one clearly presented runtime resource:

| Class | Runtime resource/state | Display |
|---|---|---|
| Arcanist | `Arcane Sequence`, 0–10 stacks | Ten small pips above the skill bar |
| Legion Commander | `Command`, generated by active allied units and summon actions | Compact banner meter |
| Bloodbinder | `Blood Debt`, health spent recently | Red segmented meter next to tower life |
| Usurper | `Discord`, generated by manipulated enemies damaging their former allies | Violet eye meter |
| Fortress Architect | `Build Supply`, recharging placement budget | Gear/hex pips near structure skills |
| Stormcaller | `Charge`, 0–6, earned mainly by triggering different reactions | Six lightning segments around the reaction tracker |
| Chronomancer | `Paradox`, debt created by moving events through time | Split clock ring with debt ticks |
| Bounty Hunter | `Trophies`, earned by completing marked-target conditions | Wanted posters/pips beside the target frame |
| Plaguewright | `Biomass`, harvested from infection growth and infected deaths | Organic flask segmented by mutation type |
| Salvager | `Scrap`, recovered from battlefield remains | Metal heap counter with projected build cost |
| Beastmaster | `Bond`, tracked separately for each persistent beast | Portrait rings around each beast command slot |
| Artillerist | `Targeting Data`, earned by accurate predicted strikes | Coordinate/reticle meter |
| Void Shepherd | `Instability`, rises when space is manipulated | Cracked portal ring with warning thresholds |
| Oathkeeper | `Resolve`, earned by completing explicit defensive vows | Shield segments and active vow timer |
| Fatebinder | `Fate`, banked from exposed deterministic outcomes | Visible card/roll queue |

Resources belong to the simulation, not the UI. They advance only on simulation ticks, are included in state hashes and replays, and expose read-only snapshots to presentation.

Pure-class ultimate routing is now represented in the simulation: a loadout with at least three matching primary skills receives a deterministic class-resonant ultimate payload while retaining the separately selected base ultimate and its long cooldown. The current payloads cover Arcanist burst cadence, Legion reinforcements, Bloodbinder tithe, Usurper conversions, Architect structures, Chronomancer time suppression, Bounty execution, Plague spread, Salvager machinery, Beastmaster apex buff, Artillerist prediction strike, Void displacement, Oathkeeper protection, Fatebinder event banking, and the existing Stormcaller Perfect Storm. The HUD now resolves and displays the themed class-ultimate name, while the selected base ultimate remains available in loadout and replay data.

### 3.2 Interaction vocabulary

Use a small reusable vocabulary in descriptions and authored data:

- `Generate`: add class resource.
- `Consume`: remove all or a stated amount for an effect.
- `Prime`: create a temporary state used by another skill.
- `Command`: apply an order to allied units.
- `Sacrifice`: deliberately destroy an allied summon and attribute the result to the caster.
- `Corrupt`: temporarily change an enemy's allegiance or targeting.
- `Construct`: create a wall, tower, trap, or aura building.
- `Resonate`: an interaction enabled by the matching class ultimate or pure-class loadout.

Descriptions must state generation, maximum stacks, duration, consumption, target rules, and boss exceptions. Never hide these rules behind class flavor text.

### 3.3 Skill-tree topology

Keep the existing predictable tree shape:

```text
Root skill
  -> Tier 1: two generic multi-rank nodes
  -> Tier 2: choose one of two specialization gateways
  -> Tier 3: branch mastery and interaction node
  -> Tier 4: rule-changing capstone
```

The player may purchase both branches in the Workshop but equips only one branch per run. Tier-1 power should be modest. Tier-4 talents should change targeting, resource use, summon behavior, or battlefield rules rather than simply adding a large multiplier.

### 3.4 Equipped passives and class doctrines

Resource collection and essential class setup should not consume most of the player's active attention. The player should make interesting decisions about **where and when to spend resources**, not repeatedly press a maintenance button before being allowed to use the class.

Use a hybrid passive model:

1. **Intrinsic equipped passive:** every skill may grant one small passive while it is equipped. This passive is part of the skill definition and always active; it does not consume another slot.
2. **Class doctrine:** reaching three matching class skills lets the player choose one of two or three class-level passives before the run. The doctrine changes priorities or resource flow rather than adding generic damage.
3. **Active override:** a skill may still have an active cast that redirects, accelerates, or temporarily overclocks its passive system. Ignoring the active override never disables the baseline economy.

Examples:

- Equipping any Salvager construction skill activates one basic Recovery Drone. Equipping the dedicated drone skill improves the passive network; its active cast becomes `Drone Overdrive`, a temporary speed boost for drones already in flight, not a drone-summoning requirement.
- Equipping Patient Zero allows infected remains to produce Biomass automatically. Vector Swarm may add passive carrion insects that collect nearby samples while its active cast commands a rapid disease transfer.
- Equipping a Beastmaster companion skill keeps that creature present and gaining Bond; commands are active skills layered on top.
- Equipping an Architect trap skill may slowly fabricate one replacement trap charge between waves, while placement remains active.

Passive grants must obey these rules:

- Passives are explicit in loadout cards, tooltips, skill-tree previews, and replay/content fingerprints.
- The loadout identity panel lists all active passives and explains which equipped skill supplied each one.
- Bridge skills grant only their authored passive; sharing two class tags does not duplicate the passive or count it twice.
- Removing a skill removes its passive before the run begins. Mid-run challenge effects that disable a skill define whether its passive pauses or remains.
- Multiple passives affecting the same system combine through authored caps and priority rules, never arbitrary multiplicative stacking.
- Passive collection, targeting, and spawning use deterministic selectors and stable entity IDs.
- A class must remain functional if the player never presses an economy-management active. Active management improves efficiency or precision; it is not an entrance fee.

## 4. Arcanist — hard-cast damage and control

### Intended play

The Arcanist constantly aims and casts abilities. Fast spells build `Arcane Sequence`; slower spells consume it for a payoff. This is the most input-heavy class and should reward timing, target selection, and holding a finisher for the correct wave shape.

`Arcane Sequence` lasts 6 seconds, refreshes when another stack is gained, stacks to 10, and increases the next consuming skill's damage by 10% per stack. A consuming skill removes all stacks after its damage snapshot is resolved. The UI must preview the currently empowered value before confirmation.

### Skills

#### 4.1 Arc Bolt

- **Target:** enemy or world-point quick cast.
- **Baseline:** fire a small projectile every 1 second for light single-target damage.
- **Interaction:** each successful cast grants one `Arcane Sequence` stack, even if the target dies before impact. Missing or cancelling grants nothing.
- **Purpose:** reliable stack builder and low-health cleanup, not a primary damage source by itself.
- **Tree ideas:**
  - Generic: projectile speed; slightly longer sequence duration.
  - `Forked Script`: bolt splits into two weaker bolts; only the primary cast grants one stack. Capstone makes every fifth cast fork toward all nearby marked enemies.
  - `Perfect Cadence`: remains single-target but every consecutive cast within 1.2 seconds gains accuracy and minor damage. Capstone grants two stacks on a perfectly timed cast, with an internal cooldown.

#### 4.2 Detonation Sigil

- **Target:** area.
- **Baseline:** delayed large-area explosion with an 8-second cooldown.
- **Interaction:** consumes all `Arcane Sequence`; gains 10% damage per consumed stack.
- **Purpose:** main wave-clear payoff.
- **Tree ideas:**
  - Generic: radius; reduced arming delay.
  - `Rolling Detonation`: lower initial damage, then two smaller explosions move outward. Capstone leaves burning ground.
  - `Compressed Rune`: smaller area and longer delay, but high center damage. Capstone refunds up to three sequence stacks when it hits only one enemy.

#### 4.3 Glacial Pulse

- **Target:** area.
- **Baseline:** deals moderate damage and applies an area slow for several seconds.
- **Interaction:** does not normally consume Sequence; at 5 or more stacks it gains increased slow strength while preserving the stacks.
- **Purpose:** hold enemies inside Detonation Sigil or the tower's firing lane.
- **Tree ideas:**
  - Generic: radius; slow duration.
  - `Permafrost`: low damage, long slow, and gradual freeze buildup. Capstone causes the next consuming spell to shatter frozen enemies.
  - `Cold Snap`: short strong slow with higher impact damage. Capstone pulls affected enemies slightly toward the pulse center.

#### 4.4 Astral Lance

- **Target:** one enemy; channeled.
- **Baseline:** maintain a beam on one target for 4 seconds, dealing substantial damage over time. Movement outside range breaks the channel.
- **Interaction:** consumes Sequence gradually, one stack per channel interval, increasing that interval's damage by 10%. This prevents a full ten-stack beam from front-loading all damage.
- **Purpose:** boss, tank, and elite removal.
- **Tree ideas:**
  - Generic: channel range; reduced cooldown after a complete channel.
  - `Execution Ray`: damage ramps against the same target and finishes with a burst. Capstone executes non-boss enemies below a health threshold.
  - `Prismatic Conduit`: lower primary damage, but the beam refracts to nearby enemies. Capstone transfers remaining channel time to a new target when the first dies.

#### 4.5 Vector Wave

- **Target:** direction.
- **Baseline:** a narrow force wave deals light damage and pushes enemies along the chosen direction.
- **Interaction:** at maximum Sequence, the wave can be cast without consuming stacks and briefly exposes displaced enemies to the next finisher.
- **Purpose:** active lane shaping and emergency control.
- **Tree ideas:**
  - Generic: width; displacement strength.
  - `Repulsion Formula`: stronger push and wall collision damage. Capstone creates a short-lived impassable force line for enemies but not projectiles.
  - `Convergence Formula`: reverses the wave into a pull toward its center line. Capstone groups affected enemies at the endpoint.

### Arcanist ultimate — Grand Equation

- Pause normal skill cooldown loss for neither the player nor enemies; simulation continues normally.
- For 10 seconds, direct-cast skills have 35% shorter cooldowns, Arc Bolt can overcap Sequence to 15, and consuming skills spend only half their stacks.
- The final cast during the effect repeats once at 40% power after a short delay.
- Legendary branches: `Endless Formula` emphasizes rapid casting and stack retention; `Cataclysm Proof` emphasizes one enormous final consuming spell.

### Pure-class resonance

At five Arcanist skills, consuming 10 stacks creates `Afterimage`: the next non-consuming Arcanist spell repeats at 30% effect. It cannot recursively trigger itself.

The runtime now arms `Afterimage` when a five-skill Arcanist consumes a full ten-stack Arcane Sequence. The next non-consuming Arcanist damage spell receives one 30% damage repeat, emits an `afterimage` event, clears the flag, and cannot recursively arm itself. The ready state is visible in the contextual HUD and included in replay hashing.

## 5. Legion Commander — numerous summons and army buffs

### Intended play

The Legion Commander fills the field with inexpensive allied units, then uses area orders to turn quantity into temporary power. Individual summons should be replaceable; preserving the whole army and timing buffs matters more than protecting one elite unit.

`Command` is gained when a summon is created and slowly while allied units are actively fighting. Orders consume Command. Global and per-skill summon caps remain mandatory.

### Skills

#### 5.1 Conscript Wave

- Summon several short-lived melee soldiers at a target point.
- `Mass Recruitment`: more weaker soldiers; capstone replaces expired soldiers if unit cap permits.
- `Veteran Detail`: fewer durable soldiers; capstone promotes survivors after enough kills.

#### 5.2 Drone Brood

- Release fast ranged drones that choose nearby targets.
- `Hunter Network`: focus one marked enemy; capstone shares overkill damage across the network.
- `Disruptor Cloud`: lower damage but applies slow and weakness; capstone spreads one debuff when a drone dies.

#### 5.3 Rally Standard

- Place an area banner that heals allied units and increases attack and movement speed. Consumes Command based on affected unit count.
- `War Chorus`: favors attack speed and damage; capstone causes kills inside the aura to extend its duration within a hard cap.
- `Sheltering Colors`: favors healing, shields, and resistance; capstone prevents one lethal hit per newly summoned unit.

The authored `FIELD REVIVE` branch now keeps a defeated non-beast summon in a one-second replay-hashed downed window. The next Rally Beacon cast can restore at most one such summon to 35% health and emits a distinct revive event; ordinary Rally Beacon casts and expired downed windows leave the baseline summon rules unchanged.

The Drone Swarm `PREDATOR LOCK` branch now spawns hunter-role drones that prioritize the highest-health living enemy. A hunter capstone hit applies a short vulnerability mark to that target and emits a target-lock event, allowing tower and allied damage to capitalize without creating an additional damage-over-time system.

#### 5.4 Forward Barracks

- Construct a temporary building that periodically produces soldiers.
- `Recruitment Center`: rapid basic-unit production; capstone lets nearby summon skills deposit replacement recruits into its queue.
- `Field Armory`: slower elite production; capstone copies one compatible damage/status tag from the tower weapon.

#### 5.5 Coordinated Assault

- Mark an area or enemy; all allied units retarget and gain a short pathing/attack bonus toward it.
- `Encirclement`: units spread around the target and gain flanking damage; capstone prevents excess units from blocking each other.
- `Focused Volley`: ranged allies synchronize one burst; capstone refunds Command for each distinct summon type participating.

### Legion Commander ultimate — Planetary Muster

- Immediately refresh a portion of every summon skill cooldown.
- Spawn one temporary command ship or command structure that raises the allied-unit cap, produces basic reinforcements, and emits a weaker Rally Standard aura for 15 seconds.
- When it expires, surviving temporary reinforcements do not become permanent; they complete their normal lifetimes.
- Legendary branches: `Endless Battalion` maximizes unit count; `Elite Cohort` converts reinforcement quantity into fewer specialized units.

### Pure-class resonance

At five Legion skills, every third summon cast issues a free minor order based on the newest unit type: melee units gain shields, ranged units gain attack speed, and support units pulse healing.

## 6. Bloodbinder — tower health as spell fuel

### Intended play

The Bloodbinder deliberately spends tower health to cast effects stronger than ordinary cooldown skills, then recovers by draining allied summons. It must feel dangerous but controllable. The UI always previews post-cast tower health and refuses an invalid sacrifice.

Blood costs use a mixture of flat health and percentage of maximum health. A normal blood skill cannot reduce the tower below 1 health. Talents that permit lethal overcasting must be explicit capstones and provide a deterministic survival rule. Healing from sacrificed summons is based on their remaining health with a conversion cap, preventing infinite summon-and-drain loops.

`Blood Debt` records health spent in the last 12 seconds. Some skills scale with or clear it. Ordinary repair effects should be less efficient while Blood Debt is high.

#### Implemented vertical slice

The reusable health transaction now lives in authored skill data rather than a class-specific UI switch. `health_cost` is validated, shown on the skill card and loadout details, rejected when it would reduce the tower to zero, included in the content fingerprint, and rolled back if an authored operation cannot execute. The simulation records `bloodDebt` in the replay hash. `Blood Lance` uses that transaction for area damage, `Hemorrhage Field` creates a debt-generating damage zone, `Blood Golem` converts health into a durable ally, `Last Pulse` spends debt on a finisher, and `Life Siphon` deterministically sacrifices the lowest-health eligible allied summon, restores capped tower health, and clears part of the debt. The themed Red Eclipse payload still builds on this authored set.

### Skills

#### 6.1 Crimson Spear

- Spend a small amount of tower health to fire a piercing high-damage projectile.
- `Open Vein`: lower cooldown and escalating cost; capstone makes every fourth spear free but weaker.
- `Coagulated Lance`: longer cooldown, wider projectile, and reduced cost; capstone leaves a damaging trail.

#### 6.2 Hemorrhage Field

- Spend tower health to create a damage-over-time area that becomes stronger with current Blood Debt.
- `Sanguine Flood`: larger area and longer duration; capstone spreads to one nearby enemy cluster after enough deaths.
- `Clotting Curse`: smaller field that heavily slows and weakens; capstone returns a fraction of its cost if it controls enough enemies without killing them.

#### 6.3 Life Siphon

- Target allied summons in an area, destroy or heavily damage them, and restore tower health based on their remaining health.
- Never targets the tower, permanent story allies, or challenge-protected units.
- `Harvest`: sacrifices all eligible units for efficient immediate healing; capstone converts excess healing into a temporary shield.
- `Tithe`: drains only a portion from each unit and leaves survivors weakened; capstone grants survivors a desperate damage buff.

#### 6.4 Blood Golem

- Spend tower health to summon one durable melee construct whose maximum health partly reflects the cost paid.
- `Guardian Flesh`: taunts and intercepts enemies; capstone redirects a limited amount of tower damage into the golem.
- `Ravenous Flesh`: loses health over time but deals strong area damage; capstone grows when nearby summons are sacrificed.

#### 6.5 Last Pulse

- Consume all Blood Debt to release a tower-centered shockwave. More debt increases radius, damage, and knockback.
- `Merciful Pulse`: lower damage, heals allied summons, and clears more Debt; capstone revives one recently destroyed non-elite summon at low health.
- `Ruinous Pulse`: higher damage and no ally healing; capstone spends additional tower health to repeat at the outer edge.

### Bloodbinder ultimate — Red Eclipse

- For 10 seconds, blood skills spend temporary `Eclipse Health` before real tower health.
- Damage dealt by blood skills replenishes a limited portion of Eclipse Health.
- When the effect ends, unused Eclipse Health disappears; it never becomes free permanent healing.
- Legendary branches: `Devouring Moon` emphasizes summon sacrifice and recovery; `Martyr Star` allows dangerous low-life spell amplification.

### Pure-class resonance

At five Bloodbinder skills, sacrificing a summon grants one `Heart Fragment`. At three fragments, the next blood-cost skill pays half cost. Fragments expire after the wave and cannot be generated by summons created for free by the same cast chain.

## 7. Usurper — enemy infighting and manipulation

### Intended play

The Usurper avoids direct damage and makes enemy formations collapse into infighting. Manipulated enemies use deterministic allegiance and targeting rules. Bosses cannot be permanently converted; control on bosses becomes taunt, confusion, vulnerability, or spawned echoes instead.

`Discord` is generated only when one enemy damages another because of a Usurper effect. This prevents the class from charging its ultimate through passive tower damage.

#### Implemented vertical slice

The simulation now carries deterministic enemy allegiance, conversion duration, confusion duration, and Discord in the state hash. `Treason Mark` selects one stable non-boss target, converts it for a bounded window, and exposes it. `Riot Whisper` and `False Orders` convert or confuse bounded clusters with boss-safe exposure fallbacks. `Puppet Thread` provides a single controlled target, while `Shared Agony` creates a capped damage-link zone. Converted and hostile enemies can attack opposing enemies using stable distance/ID tie-breaking, and each friendly-fire event produces capped Discord. Recursive conversion is not triggered by friendly fire, so riots cannot amplify themselves indefinitely. The themed Coup d'État payload still builds on this primitive.

### Skills

#### 7.1 Treason Mark

- Mark one non-boss enemy so nearby enemies treat it as hostile for a short duration.
- `Scapegoat`: marked target gains threat and resistance so the mob focuses it longer; capstone explodes the mark when the target dies.
- `Turncoat`: marked target actively attacks former allies; capstone retains one compatible special attack at reduced power.

#### 7.2 Riot Whisper

- Apply confusion in an area; affected enemies choose other affected enemies as temporary targets.
- `Mass Hysteria`: larger area and more targets but shorter duration; capstone spreads once when two confused enemies kill each other.
- `Calculated Revolt`: smaller area and deterministic focus on the strongest enemy; capstone makes weaker enemies coordinate against it.

#### 7.3 Puppet Thread

- Channel control over one enemy, manually retargeting it while the channel lasts. The tower cannot use another channeled skill simultaneously.
- `War Puppet`: controlled enemy gains attack speed against enemies; capstone copies part of elite on-hit behavior.
- `Living Shield`: controlled enemy prioritizes interception and absorbs projectiles; capstone transfers remaining shield value into Discord when it dies.

#### 7.4 False Orders

- Place a deceptive signal that redirects enemy movement and attacks for a short period.
- `Phantom Tower`: enemies waste attacks on a decoy; capstone reflects a small fixed portion of attack damage.
- `Open Flank`: enemies reroute through a chosen exposed lane and lose resistance; capstone causes the first enemy entering to be Treason Marked.

#### 7.5 Shared Agony

- Link several enemies so a percentage of damage they deal to each other is repeated across the link.
- `Pain Chorus`: supports large groups and repeated small hits; capstone extends the link when a member dies.
- `King's Burden`: links one elite to nearby lesser enemies; capstone redirects part of the elite's damage into its followers.

### Usurper ultimate — Coup d'État

- For 12 seconds, all non-boss enemies in a large area split into two hostile factions and prioritize the opposing faction.
- Newly spawned enemies join the faction with fewer living members for deterministic balancing.
- Bosses instead become highly threatening to nearby enemies and take increased damage from enemy attacks.
- Legendary branches: `Civil War` maximizes duration and faction size; `Perfect Usurpation` temporarily converts one elite champion into a controllable ally.

### Pure-class resonance

At five Usurper skills, every third enemy-on-enemy kill creates a short-lived rebel echo that attacks enemies. Echoes cannot generate more echoes or Discord.

The pure Usurper resonance is now live: the existing deterministic infighting path counts only actual enemy-on-enemy deaths, spawns one capped `rebel_echo` ally on every third kill for a short lifetime, and hashes both the kill counter and echo count. Echo attacks use ordinary allied targeting and cannot feed back into Discord or create additional echoes.

## 8. Fortress Architect — walls, towers, and path control

### Intended play

The Fortress Architect places structures that alter enemy routes. This is the most technically demanding class because placement affects navigation. Enemies route around walls when a path exists. If structures fully block every valid route, enemies attack the blocking structures instead of becoming stuck.

#### Implemented vertical slice

`Bulwark Wall` and `Trap Foundry` now use authored placement operations. Walls are deterministic, attackable blockers with contact damage, while traps are non-spawning floor entities with authored charges, rearm timing, area damage, trigger visuals, and replay-hashed state. This is the first structure primitive for the later authoritative navigation graph; the current lane model makes blocked contact explicit before full route-cache invalidation and multi-route queries are added.

`Build Supply` limits simultaneous construction bursts. It recharges over time and between waves. Structures still have cooldowns, health, lifetime where appropriate, and per-type caps.

The runtime now exposes `Build Supply` as a replay-hashed 0–100 placement budget for Architect-tagged loadouts. Walls, Foundry traps, Salvager mines, and Salvager turrets placed from an Architect loadout spend authored fixed supply costs; failed placements do not consume it. Supply regenerates one point every half-second and receives a between-wave refill, while non-Architect loadouts remain unaffected. The HUD displays `BLD current/cap` alongside the other contextual resources.

### Navigation contract

- Build a deterministic navigation grid or lane graph in simulation coordinates. Do not use renderer pixels.
- Every blocking placement runs a path-existence query before confirmation.
- A legal placement may lengthen the path or close some routes.
- If no route remains, identify the minimum deterministic set of blocking structures between the enemy and tower. Enemies attack the nearest reachable blocker, breaking ties by structure ID.
- After a blocker is destroyed, recompute or invalidate the cached route.
- Flying, phasing, burrowing, and boss enemies may have authored traversal exceptions, clearly shown in challenge/enemy descriptions.
- Prevent tiny diagonal gaps that look closed but are navigable. Placement footprints and navigation cells must share one authoritative geometry representation.

### Skills

#### 8.1 Bulwark Wall

- Place a durable wall segment that blocks ground movement and projectiles according to facing.
- `Rampart Line`: supports linked segments and gains health when connected; capstone lets one cast place a short line preview.
- `Reactive Plating`: damages enemies attacking it; capstone releases a knockback pulse when destroyed.

#### 8.2 Sentry Fabricator

- Place a temporary autonomous tower.
- `Gatling Nest`: ramps against one target; capstone preserves part of its ramp when switching targets.
- `Mortar Post`: slow area shells over walls; capstone leaves a short slow crater.

#### 8.3 Arc Pylon

- Place two pylons that create a damaging or slowing line between them.
- `Kill Corridor`: line deals increasing damage to repeated crossers; capstone lets connected sentries fire along the line.
- `Containment Fence`: low damage, strong slow, and path discouragement; capstone briefly stuns enemies that break a connected wall.

#### 8.4 Repair Station

- Construct a small building that repairs nearby walls, towers, and allied buildings.
- `Maintenance Drones`: mobile repair pulses; capstone automatically prioritizes the structure currently blocking enemies.
- `Overclock Bay`: less repair, grants structure attack speed and range; capstone refreshes one nearby structure's limited-duration timer.

#### 8.5 Demolition Charge

- Attach a charge to one owned structure or empty ground and manually detonate it for area damage.
- `Controlled Demolition`: refund Build Supply when destroying an owned structure; capstone rebuilds a weaker wall foundation after the blast.
- `Seismic Charge`: larger enemy-focused explosion and terrain slow; capstone chains to adjacent wall segments without damaging allied towers.

#### 8.6 Trap Foundry

- **Target:** placement on a valid walkable navigation cell.
- **Baseline:** place a compact floor trap with limited charges. It triggers when a ground enemy crosses its footprint, damages enemies in a small area, then rearms after a short delay. Traps do not block movement; their strength comes from using walls and pylons to funnel enemies repeatedly across prepared ground.
- **Build Supply:** costs less Supply than a wall or tower, allowing several traps to define a kill corridor. Global and per-type trap caps prevent covering the entire map.
- **Placement preview:** show the trap footprint, trigger area, current enemy route, estimated crossings, remaining charges, and whether another trap is too close. A trap may be placed beneath a predicted route but not beneath an enemy already occupying the cell.
- **Ownership:** trap damage, status uptime, kills, and triggered reactions are attributed to Trap Foundry even when walls caused the route that led enemies across it.
- **Tree ideas:**
  - Generic: additional charge; shorter rearm time; slightly larger trigger footprint.
  - `Incendiary Plates`: the impact deals lower immediate damage but ignites enemies and leaves a brief burning patch. Tier-3 talents increase burn duration or spread Burn to tightly grouped enemies. The capstone, `FIREBREAK`, causes burning enemies to leave short-lived flame trails when forced through a connected wall corridor; trails cannot recursively create more trails.
  - `Cryo Snares`: deals light damage and applies a strong slow. Repeated triggers build toward a short freeze. Tier-3 talents improve rearm speed or make frozen enemies take additional structure damage. The capstone, `PERMAFROST CHANNEL`, links nearby Cryo Snares so triggering one briefly primes the next trap in the route for a stronger slow.
  - Optional later branch, `Arc Conduits`: low direct damage, but chains lightning between nearby traps, pylons, and sentries. The capstone lets one trigger discharge through the whole connected Defense Network with a strict target and reaction cap.

##### Trap and funnel rules

- Walls may lengthen a route to create extra trap crossings, but enemies should remember recently crossed navigation edges. They must not oscillate between two equally valid cells merely to trigger a trap repeatedly.
- Route selection uses structure geometry and travel cost, not knowledge of trap damage by default. An enemy with an authored `cautious` or `engineer` trait may add trap danger to its path cost and choose a safer route.
- Traps trigger once per enemy entry, not once per simulation tick. An enemy must leave and legitimately re-enter the trigger footprint before it can activate the same trap again.
- A trap in its rearm period remains visible and non-triggering. The HUD and world graphic show charges and rearm progress.
- Large enemies may trigger multiple adjacent traps only when their center enters each distinct footprint. Collision radius alone must not consume an entire corridor at once.
- Flying or phasing enemies ignore floor traps unless a talent explicitly adds an anti-air or phase-detection effect.
- Bosses trigger traps normally but use authored resistance to hard control. Freeze converts to a strong slow when boss freeze immunity applies.
- Damage-over-time zones from traps have hard global caps and refresh/replace rules. Overlapping fire patches refresh duration before adding damage stacks.
- Enemies attacking a fully blocking wall remain valid trap targets only if they actually stand inside a trap footprint; wall contact alone does not trigger nearby traps.
- Selling, replacing, expiring, or demolishing a trap must invalidate its pending trigger safely and preserve deterministic replay state.

### Fortress Architect ultimate — Citadel Protocol

- Deploy a temporary central command bastion at a valid location.
- The bastion increases nearby structure caps, repairs walls, and grants all structures a target-coordination aura for 15 seconds.
- During the protocol, traps inside the bastion network rearm faster and do not consume their final charge until the ultimate ends. This strengthens an existing funnel without creating traps automatically in invalid locations.
- It includes two temporary wall anchors, but placement must still obey the navigation contract.
- Legendary branches: `Unbreakable City` emphasizes walls and repair; `Artillery Network` links all towers into coordinated area fire.

### Pure-class resonance

At five Architect skills, connected structures form a `Defense Network`. Each distinct structure type contributes one limited bonus: wall health, tower range, repair efficiency, or Build Supply regeneration. Duplicate spam does not stack the network bonus.

## 9. Stormcaller — elemental sequencing and chain reactions

### Intended play

The Stormcaller fills enemy groups with elemental states, reads what is currently active, and chooses the next spell to trigger the best reaction. It is a spell-order class rather than a generator-and-finisher class.

Arcanist asks, `How many Sequence stacks can I build before spending them?` Stormcaller asks, `Which state is on which enemies, which reaction should happen next, and which state do I need to preserve for the following cast?`

Stormcaller uses `Charge`, but Charge is a supporting reward rather than the central rotation. Triggering an elemental reaction grants one Charge. Triggering a reaction with a different ID from the previous reaction grants one additional Charge, up to 6. Repeating the same reaction remains useful but is less efficient. Charge decays one point every 5 seconds after 8 seconds without a Stormcaller cast or reaction.

Charge improves utility rather than adding a universal damage multiplier. Individual skills may spend it to extend a chain, preserve one state, increase a pull, or accelerate a storm. The player must always be able to cast at zero Charge.

#### Implemented vertical slice

The runtime now includes the first authored Stormcaller sequence. `Flash Flood` accepts a direction target, pushes and Soaks enemies along a bounded wave, `Thunderhead` creates a pulsing Shock cloud, `Thermal Surge` applies Ignite and resolves Plasma/Steam reactions, and `Eye of the Storm` pulls a group and resolves one prepared Shock+Soak burst. Charge is capped at six, distinct reaction IDs grant the documented bonus Charge, reaction events are capped at 24 per cast, and Charge/reaction state is included in replay hashing. The bounded reaction path now also includes a non-recursive `Shatter` result for direct resolution against Frozen targets. The reaction priority, state-transfer, per-target cooldown, generation-depth, and setup-provenance fields now come from the authored reaction registry; Firestorm and Supercell are legal registry-selected outcomes when their states and zones are present. The HUD exposes Charge, the pure-resonance sequence, and Perfect Storm time remaining; skill icons and world visuals identify the four new spells, and all four have generic/two-branch/tier-four authored talent trees. The first behavior-specific branches are now live: `Pursuing Tempest` moves Thunderhead toward the strongest nearby enemy, `Storm Tracking` improves reacquisition speed, `Double Eye` emits a bounded second pulse, `Undertow` pulls Flash Flood targets toward its centerline, and `Wildfire` spreads a reduced Ignite with a mastery radius increase. Perfect Storm now preserves states and, for each distinct reaction during its window, either emits a reduced pulse from an active Thunderhead or grants one Charge when no cloud is present. Pure resonance echoes the third distinct reaction at reduced strength without consuming setup states.

The shared Cryo Field branch also implements behavior-specific `WHITEOUT`: with its capstone equipped, enemies touched by the field carry a two-second replay-hashed post-zone slow whose strength fades toward the authored floor. The timer refreshes only while an enemy is actually inside the field, so it cannot become a permanent global slow.

### Elemental-state contract

Use explicit authored states with visible duration rings and stable IDs:

| State | Baseline effect | Primarily applied by |
|---|---|---|
| `Soaked` | No damage by itself; prepares conductive, freezing, and steam reactions | Flash Flood |
| `Shock` | Small periodic damage and one conductive marker | Thunderhead, Chain Lightning |
| `Freeze` | Strong control; bosses receive `Deep Chill` instead of full immobilization | Cold talents and cross-class Cryo skills |
| `Ignite` | Damage over time | Thermal Surge and fire talents |
| `Gale` | Brief displacement/exposure state; marks enemies as wind-affected | Eye of the Storm and wind talents |

State application and reaction resolution are separate operations. Applying a state first checks whether the target already carries a compatible state. If so, resolve one authored reaction, consume or transform the specified states, apply the new state only when the reaction says to do so, then enforce the per-cast reaction budget.

### Initial reaction table

| Reaction | Required order/state | Result | Default consumption |
|---|---|---|---|
| `Conductive Arc` | Apply Shock to a Soaked enemy | Lightning gains additional bounce range and jumps through nearby Soaked enemies | Consume Soaked from enemies used as bonus conductors; preserve Shock |
| `Flash Freeze` | Apply Freeze or strong cold to a Soaked enemy | Freeze builds instantly and emits a small slowing splash | Consume Soaked; apply Freeze |
| `Shatter` | Deal direct or force damage to a Frozen enemy | Fire deterministic ice fragments at nearby enemies | Consume Freeze; fragments apply Deep Chill but cannot Shatter again |
| `Firestorm` | Apply Gale to an Ignited enemy | Spread a portion of Ignite to nearby enemies along the wind direction | Consume Gale and reduce, rather than remove, the source Ignite duration |
| `Plasma Burst` | Apply Shock to an Ignited enemy | Produce a compact high-damage plasma explosion | Consume Shock and Ignite |
| `Steam Burst` | Apply Ignite to a Soaked or Frozen enemy | Area damage, short push, and brief accuracy/visibility weakness | Consume Soaked or Freeze; apply a shortened Ignite only with a talent |
| `Supercell` | Pull a Soaked and Shocked cluster into an active storm | Thunderhead immediately pulses once with reduced reaction damage | Consume Soaked; preserve one Shock application per target |

Order matters. Shock followed by Ignite may simply leave both states until another effect triggers Plasma Burst, while Ignite followed by a Shock-applying spell triggers it immediately. Tooltips must show `APPLIES`, `REACTS WITH`, `CONSUMES`, and `LEAVES` as separate lines.

### Reaction safeguards

- A reaction carries `source_cast_id`, `reaction_id`, and `generation_depth`.
- Secondary fragments, chains, hazards, and repeats cannot trigger the same reaction that created them unless an authored capstone explicitly permits one extra generation.
- Default maximum is one primary reaction per target per cast and 24 total reaction events per cast. Content may lower this limit but may not silently exceed the global safety cap.
- When several reactions are legal, use authored priority, then oldest existing state, then stable state ID. Do not depend on JSON or container iteration order.
- Reaction damage receives one attribution record containing the setup skill, triggering skill, and owning loadout. Kills belong to the triggering skill while telemetry credits setup contribution separately.
- Bosses keep reaction damage but convert hard Freeze, large displacement, and confusion into authored resistant versions.
- Cross-class elemental effects can participate only when tagged `reaction_compatible`. This prevents every incidental Burn or Slow upgrade from unexpectedly feeding Stormcaller.

### Skills

#### 9.1 Thunderhead

- **Target:** world point followed by a direction or destination.
- **Baseline:** summon a slow-moving storm cloud for 7 seconds. It travels along the chosen line, periodically dealing light area damage and applying Shock.
- **Role:** persistent Shock applicator and moving reaction engine. Its pulses are deliberately modest without prepared states.
- **Charge interaction:** spend up to 2 Charge when cast; each point adds one pulse over the same duration instead of multiplying pulse damage.
- **Tree ideas:**
  - Generic: cloud radius; duration; travel speed control.
  - `Pursuing Tempest`: cloud follows the highest-health enemy in range at limited speed. Tier-3 nodes improve reacquisition or boss tracking. Capstone `RELENTLESS FRONT` transfers the cloud to the nearest Shocked enemy when its target dies, preserving remaining duration.
  - `Static Supercell`: cloud remains at the target point with larger radius and slower pulses. Tier-3 nodes improve Conductive Arc or Supercell reactions. Capstone `DOUBLE EYE` creates two smaller linked clouds; an enemy can be damaged by both, but receives Shock from only one pulse per interval.

#### 9.2 Flash Flood

- **Target:** direction.
- **Baseline:** send a broad wave forward, dealing light damage, pushing normal enemies, and applying Soaked for 6 seconds.
- **Role:** formation setup, emergency displacement, and the main enabler for conductive or freezing sequences.
- **Charge interaction:** at 3 or more Charge, hold the cast button to spend 1 Charge and widen the wave preview before release.
- **Tree ideas:**
  - Generic: width; Soaked duration; moderate push strength.
  - `Deluge`: wider, slower wave with longer Soaked duration. Tier-3 nodes leave shallow water briefly or improve Flash Freeze. Capstone `FLOODPLAIN` causes the first Conductive Arc in the water to treat all enemies standing in it as Soaked without consuming the field itself.
  - `Undertow`: weaker forward push followed by a pull toward the wave centerline. Tier-3 nodes improve grouping and Supercell setup. Capstone `RIP CURRENT` carries small enemies a limited distance with the wave; bosses receive only Deep Chill-like movement reduction.

#### 9.3 Chain Lightning

- **Target:** one enemy.
- **Baseline:** strike a target and bounce to nearby enemies. It applies Shock to unshocked targets. If the primary target is already Shocked, consume its Shock to gain more bounces, range, and damage decay resistance.
- **Role:** direct reaction trigger and cleanup spell. It is strongest after Thunderhead or Flash Flood has prepared a formation.
- **Charge interaction:** spend 1 Charge to preserve Shock on the primary target after using its aggressive-chain bonus.
- **Tree ideas:**
  - Generic: initial range; one minor bounce; reduced cooldown.
  - `Forking Circuit`: each bounce prefers a different valid elemental state and can fork once with reduced damage. Tier-3 nodes improve Soaked targeting or setup credit. Capstone `LIVING CIRCUIT` makes the final bounce return to the primary target if at least three different enemies were struck.
  - `Overload`: fewer bounces but strong damage against one Shocked or elite target. Tier-3 nodes improve Plasma Burst or boss damage. Capstone `GROUND FAULT` sends excess single-target damage into a small non-recursive ground arc.

#### 9.4 Thermal Surge

- **Target:** area or directional cone, selected by equipped branch.
- **Baseline:** release heat that deals moderate damage, applies Ignite, and removes Freeze. Removing Freeze through this cast triggers Steam Burst rather than silently deleting the state.
- **Role:** Burn setup, anti-Freeze conversion, and access to Firestorm and Plasma Burst.
- **Charge interaction:** spend up to 2 Charge to preserve 25% of consumed Freeze as Deep Chill after Steam Burst, supporting a longer sequence without retaining full control.
- **Tree ideas:**
  - Generic: Ignite duration; area; shorter recovery after cast.
  - `Wildfire`: becomes a cone and spreads Ignite efficiently through grouped enemies. Tier-3 nodes strengthen Firestorm spread or burning ground. Capstone `BACKDRAFT` causes Gale applied to its Ignite to pull enemies slightly before the Firestorm pushes flame outward.
  - `Thermal Inversion`: remains a precise area and specializes in consuming Freeze/Soaked. Tier-3 nodes increase Steam Burst control or preserve Deep Chill. Capstone `ZERO TO SUN` makes the first Frozen elite hit produce a second delayed thermal ring at reduced strength.

#### 9.5 Eye of the Storm

- **Target:** area.
- **Baseline:** create a vortex that pulls enemies toward its center and gathers elemental potential. Once during its duration, it copies one eligible elemental state from enemies in the outer ring onto valid enemies near the center, then triggers the highest-priority available reaction.
- **Role:** convert a scattered, partially prepared battlefield into one deliberate large reaction. It does not duplicate arbitrary status stacks; every copied state obeys transfer and target caps.
- **Charge interaction:** consumes all Charge. Each point increases pull reliability and allows one additional state transfer, up to the authored reaction budget. Charge does not directly multiply reaction damage.
- **Tree ideas:**
  - Generic: radius; duration; status-transfer range.
  - `Convergence`: stronger grouping and prefers the most common elemental state. Tier-3 nodes improve Supercell and clustered reactions. Capstone `ELEMENTAL SINGULARITY` resolves up to two different compatible reactions in authored priority order, with the second at 60% strength.
  - `Roaming Eye`: smaller vortex that moves toward the densest eligible enemy cluster. Tier-3 nodes improve transfer frequency or travel speed. Capstone `STORM PATH` leaves a short Gale trail that can trigger Firestorm but cannot trigger another Eye of the Storm.

### Stormcaller ultimate — Perfect Storm

- **Target:** none; manually activated.
- **Duration:** 10 seconds with a long ultimate cooldown.
- Elemental reactions do not consume their required states during Perfect Storm. They still respect per-target internal cooldowns, reaction budgets, and generation-depth limits.
- The first time each distinct reaction ID occurs during the ultimate, Thunderhead immediately gains one reduced-strength pulse if a cloud is active. Without a cloud, the reaction grants one Charge instead.
- Repeating one reaction cannot dominate the window: after the first occurrence, that reaction deals normal damage but cannot trigger another bonus pulse for the rest of the ultimate.
- When Perfect Storm ends, states remain with their real remaining durations; it does not refresh every state or create permanent reaction loops.
- Legendary branch `ELEMENTAL MEMORY`: the first three distinct reactions remain non-consuming for several seconds longer, but bonus pulses stop when the base ultimate ends.
- Legendary branch `MAELSTROM CROWN`: creates one large stationary Thunderhead and improves pull/control, but reactions consume states normally after their first trigger.

### Pure-class resonance

At five Stormcaller skills, track distinct reactions in a three-step cycle. Every third reaction triggers `Echoed Reaction`, repeating that third reaction at 40% damage and 50% control duration without consuming states. The three reactions must have different IDs; repeating one reaction resets neither the cycle nor advances it. The echo has `generation_depth + 1`, cannot generate Charge, cannot advance resonance, and cannot trigger another reaction.

### Example rotations

```text
Wave clear:
Flash Flood (Soaked)
-> Thunderhead (Conductive Arc + Shock)
-> Thermal Surge (Plasma Burst on shocked ignited targets)
-> Eye of the Storm (gather and resolve the remaining best reaction)

Control and shatter:
Flash Flood (Soaked)
-> reaction-compatible Cryo effect (Flash Freeze)
-> Eye of the Storm or force hit (Shatter)
-> Chain Lightning to clean up survivors

Fire spread:
Thermal Surge (Ignite)
-> Eye of the Storm or Gale talent (Firestorm)
-> Thunderhead (Plasma Burst where Ignite remains)
```

These are useful sequences, not mandatory fixed rotations. Enemy spacing, immunities, existing tower statuses, cooldowns, and the chosen skill branches should change the best order during play.

## 10. Expansion synergy-class catalog

These classes are design-ready additions, not a requirement to ship simultaneously. Luna should implement them in dependency order and reuse the same authored skill, resource, targeting, talent-tree, replay, telemetry, and presentation contracts as the six core classes.

### 10.1 Chronomancer — timeline manipulation

#### Identity and resource

The Chronomancer changes **when** movement, attacks, cooldowns, and damage resolve. It is not a generic Slow class. `Paradox` is debt created by pulling beneficial events earlier or forcing hostile events later. Paradox ranges from 0–100 and naturally clears over time. Higher Paradox lengthens Chronomancer cooldown recovery and makes advanced casts costlier; it must never introduce random outcomes.

#### Implemented vertical slice

The existing Temporal Anchor primitive now has an authored Chronomancer companion set: `Accelerate` buffs allied units and nearby structure cadence, `Delay` suspends an eligible hostile event, `Rewind` restores enemies from a fixed eight-sample legal path ring, and `Borrowed Time` refreshes another cooling skill while adding Paradox debt. Chronomancer cooldowns scale deterministically with current Paradox, delayed enemies cannot act or advance while suspended, and `Time Fracture` now records an eight-second replay-hashed hostile timeline state that advances enemy movement, attack cooldowns, and telegraphs at a deterministic 40% cadence while allied systems continue normally. Event-specific snapshot restoration and richer scheduled-event types still extend this primitive.

Timeline edits use explicit snapshots and scheduled events. A snapshot stores only authored reversible fields. Death, rewards, boss phase transitions, and consumed one-time triggers are never silently undone.

#### Skills

- **Temporal Anchor — enemy target.** Snapshot path position, health percentage, and removable states; after 4 seconds return the living target to the snapshot. It cannot resurrect or reverse boss phases. `Prison Loop` favors position/control and caps health restoration; `Second Wound` restores position but reapplies a percentage of damage taken. Capstones either echo one short rewind or anchor a small group with strict target limits.
- **Accelerate — allied target/area.** Increase attack cadence, movement, production, and animation-safe simulation actions for one tower, structure, or summon. It does not accelerate global cooldowns. `Overclocked Arsenal` favors structures and weapons; `Rapid Evolution` favors summons and temporary growth. Capstones bank a limited number of extra actions rather than multiplying every tick.
- **Delay — enemy target.** Add time to an enemy's currently telegraphed attack, teleport, summon, or special ability. If no delayable event exists, the cast is invalid. `Stolen Moment` converts part of the delay into allied cooldown progress; `Suspended Threat` can hold one elite action longer but increases Paradox. Capstones redirect or cancel one delayed non-boss action under explicit rules.
- **Rewind — area or lane.** Move several enemies backward through recorded path-history samples, preserving legal path geometry. `Mass Reversal` affects more normal enemies; `Precise Recall` strongly rewinds one elite. Capstones leave temporal echoes or make rewound enemies repeat a recent movement segment once without repeatedly triggering traps.
- **Borrowed Time — allied skill target.** Instantly refresh another skill or restore one charge, then add Paradox debt that lengthens later Chronomancer cooldowns. It cannot target itself, another Borrowed Time, or an ultimate. `Flexible Credit` lowers immediate debt but spreads it across more cooldowns; `All In` creates heavy debt for a full refresh and temporary cast amplification. Capstones forgive debt after meeting a difficult timing condition, never automatically.

#### Ultimate — Time Fracture

For 8 seconds, enemies process movement and eligible action timers at 40% speed while allied projectiles, summons, structures, and normal cooldowns continue at standard simulation speed. Damage-over-time cadence is authored per status and does not accidentally gain extra total damage. Bosses retain a minimum action rate. `Frozen Future` emphasizes hostile-event delay; `Golden Timeline` emphasizes allied action scheduling.

#### Pure resonance and safeguards

At five Chronomancer skills, every third distinct timeline operation creates a `Stable Moment` that clears a small amount of Paradox and protects the next snapshot from early invalidation. Snapshot memory is globally capped; history uses fixed-size ring buffers; scheduled events have stable IDs and deterministic ordering. Rewind cannot duplicate rewards, trap triggers, projectiles, deaths, summons, or consumable effects.

The runtime now tracks distinct successful Chronomancer operations with a five-bit replay-hashed mask. Every third distinct operation clears eight Paradox and arms `Stable Moment`; the next Temporal Anchor snapshot becomes protected from being overwritten by another anchor until it resolves, then the protection is cleared. The HUD exposes the operation mask and ready state, and the transition emits a `stable_moment` event.

### 10.2 Bounty Hunter — elite hunting and priority targets

#### Identity and resource

The Bounty Hunter specializes in dangerous isolated targets and is intentionally weak against dense swarms. `Trophies` are earned by killing marked enemies while satisfying visible bounty conditions. A bounty grows in value while its target remains alive and dangerous, encouraging the player to control a target before executing it. Growth has a hard time/value cap so stalling is never infinite profit.

#### Skills

- **Wanted — enemy target.** Mark one eligible enemy and display its base reward, growth, and optional condition. `Dead or Alive` allows control/summon-assisted captures; `Public Enemy` raises threat and reward while empowering the target. Capstones permit two lesser marks or one high-risk elite contract.
- **Deadeye Shot — enemy target.** Long wind-up, massive single-target hit that scales with target isolation. `One Clean Shot` rewards no nearby enemies and high accuracy; `Execution Round` scales against exposed or low-health targets. Capstones refund part of the cooldown on a correct bounty execution or pierce only after killing the marked target.
- **Harpoon — enemy target and destination direction.** Pull a normal/elite enemy away from its group and briefly restrict movement. Bosses receive a short stagger/exposure instead. `Barbed Cable` adds bleed and a recast pull; `Containment Line` anchors the target to a radius. Capstones make isolation easier without permanently removing an elite from play.
- **Exploit Weakness — enemy target.** Reveal one seeded temporary weakness from valid tags such as projectile, summon, structure, elemental reaction, or direct skill. `Prepared Hunter` previews two and chooses one; `Adaptive Arsenal` accepts one weakness but increases its payoff. Capstones let the player lock a preferred category at reduced reward or chain a completed weakness into the next bounty.
- **Collector Drone — world point/automatic utility.** Deploy a drone that retrieves Trophy drops, reveals isolation radius, and lightly debuffs the active bounty. `Courier` improves collection and survival; `Spotter` improves weakness and predicted movement information. Capstones recover one missed Trophy or paint the target for allied long-range attacks.

The runtime includes a deterministic contract registry. `Wanted` and the class-resonant `Most Wanted` payload seed three visible objectives from the run seed and target ID: maintain isolation, reveal a weakness, execute a marked strike, use three distinct skill tags, interrupt a telegraph, or execute within a visible deadline. Progress is stored separately from the legacy payout counter, capped by authored thresholds, and included in the state hash. `Harpoon`, `Exploit Weakness`, `Deadeye Shot`, targeted skill-tag diversity, and telegraph timing advance the relevant objectives; deadline success is evaluated at execution. Completing objectives increases the Trophy payout, while the Collector Drone remains non-combat and only secures the active mark. The HUD and pre-cast target panel display authored objective names, descriptions, and progress. Boss-incompatible objectives resolve through authored deterministic substitutions before contract selection; remaining work is balance tuning and additional content rather than a missing contract-preview system.

Objective records now also carry authored display names and short explanations. The run HUD uses those records for the progress strip, an expanded contract detail panel, and the currently actionable subtitle, so the player can understand what each Most Wanted condition means without relying on numeric objective codes. The metadata is content-validated and changes the content fingerprint.

The Bounty Hunter talent runtime now gives contract branches authored effects: `ISOLATION` starts a bounded isolation window, `EXPLOIT` can reveal a seeded weakness when Wanted is cast, and its mastery increases the marked exposure. `ADAPTIVE READ` strengthens weakness vulnerability, `CONTRACT TERMS` lengthens marked reveals, and `BREACH OF CONTRACT` rewards the first reveal/matching hit with capped Trophy gains. `MOST WANTED` adds its extra payout only after all three visible objectives are completed; the one-time weakness reward is replay-hashed on each target.

Mutation’s authored branches now affect the epidemic transaction: `EFFICIENT CULTURE` refunds a bounded portion of Biomass when a mutation actually finds hosts, `SPORE FORM` widens rupture spread, and `BLOOMING CATASTROPHE` preserves the strongest nearby Spore strain through the rupture. `SYMBIOTIC FORM` remains the baseline husk path, while `LIVING CULTURE` strengthens the bounded husk without allowing husks to create further infection or remains.

Rupture Host’s branches are live as well: `SEPTIC BURST` increases spread radius and infection duration, `OUTBREAK CORE` leaves a short capped rupture zone that continues applying the authored strain, `VIRULENT BURST`/`LIVING CULTURE` increase the Biomass return from stack count, and `HOST HARVEST` preserves one bounded infected host after the burst. The zone is a normal replay-hashed skill zone and cannot recursively create additional rupture zones.

`PANDEMIC GENESIS` now selects the strongest infected host with a stable ID tie-break, records its strain as the replay-hashed Prime Strain, and runs a 12-second authored window. Prime copies retain full rupture potency and each Prime host may seed only one bounded secondary Vector spread; the per-host spread flag and window expiry are included in state hashing.

#### Ultimate — Most Wanted

Choose one enemy. Generate two or three deterministic objectives from its type and the current loadout, such as isolate it, hit it with three distinct skill tags, interrupt a telegraph, or kill it within 8 seconds. Objectives are seeded and previewed before confirmation. Completing objectives increases the final Trophy payout and causes a large execution strike; failure still leaves a normal Wanted mark. Boss objectives use phase-safe alternatives.

#### Pure resonance and safeguards

At five Bounty Hunter skills, completing a maximum-value bounty grants `Killing Momentum`: the next marked elite begins with one objective partially prepared but never completed automatically. Bounty targets, objective progress, seeded choices, isolation checks, and rewards enter replay/state hashes. Summoned trivial enemies, rebel echoes, and player-created units can never become profitable bounties.

The runtime now arms a one-use, replay-hashed `Killing Momentum` token only when a five-skill Bounty Hunter completes all three objectives on a maximum contract. The next `Wanted` cast selects the first multi-step objective deterministically and starts it at `target - 1`; single-step objectives remain at zero, and no objective is auto-completed. The HUD reports the pending token before the next mark.

### 10.3 Plaguewright — spreading and mutating epidemics

#### Identity and resource

The Plaguewright maintains an infection across enemy formations and deliberately mutates it. `Biomass` comes from new infections, mutation milestones, and infected enemy deaths, with diminishing gain from repeated trivial units. Diseases are authored state families, not ordinary infinitely stackable Poison.

Plaguewright corpse processing is passive once enabled by an equipped skill. The player should concentrate on infection selection, mutation timing, containment, and host rupture—not manually clicking every corpse. Infected remains expose `biomass_value`; passive carrion insects or spore collectors claim and process them using the shared remains contract.

The current runtime slice implements the epidemic loop behind authored operations: `Patient Zero` starts infection, `Vector Swarm` copies bounded generations, `Mutation` spends Biomass and records one of four deterministic strain IDs, `Rupture Host` bursts the strongest infected host and copies a reduced strain, and `Quarantine` creates an amplifying containment zone. Mutation now has an explicit four-choice selection state (`Necrotic`, `Rabid`, `Spore`, `Symbiotic`), cycled while targeting with left/right or Q/E, shown on the skill card, and included in the replay hash. Symbiotic infected natural enemies create one temporary `plague_husk` allied unit on death when the generation and global summon caps allow it; husks are ordinary allies and cannot create remains, spread infection, or create more husks. Infection strain, generation, stacks, remains, Biomass, husks, and zone state are replay-hashed. Plaguewright loadouts receive a small Biomass starter reserve so the first wave can establish an epidemic before corpse income exists; this is a bootstrap allowance, not free long-term scaling.

Core epidemic forms:

- `Necrotic`: reliable damage over time and healing reduction.
- `Rabid`: infected enemies lash out at nearby enemies, bridging into Usurper.
- `Spore`: hosts release capped infection clouds when they die.
- `Symbiotic`: killed hosts can create weak temporary allied husks, bridging into summon classes.

#### Skills

- **Patient Zero — enemy target.** Apply the base infection and bonus Biomass if it survives long enough to spread. **Equipped passive — Autopsy Protocol:** infected natural enemies leave Biomass-bearing remains that are processed automatically after a short visible delay. `Virulent Strain` spreads rapidly with weaker damage; `Terminal Strain` spreads slowly but grows lethal. Capstones preserve one mutation through a host death or create a limited elite carrier.
- **Vector Swarm — area/moving swarm.** Insects copy eligible infection states between nearby enemies. **Equipped passive — Carrion Vectors:** one small insect swarm hovers near the battlefield and automatically claims nearby Biomass remains. The active cast commands it to stop collecting briefly and perform rapid disease transfer in the targeted area. `Mosquito Cloud` maximizes spread radius; `Carrion Beetles` improve corpse processing and strengthen existing infections. Capstones cross one lane gap or carry one mutation without recursively spawning swarms.
- **Mutation — choose one mutation mode, then target infected area.** Transform the dominant infection into Necrotic, Rabid, Spore, or Symbiotic according to equipped branch. `Directed Evolution` offers precise conversion at higher Biomass cost; `Unstable Evolution` affects more hosts with reduced potency. Capstones permit one dual-trait strain under strict incompatibility rules.
- **Rupture Host — infected enemy target.** Consume infection and deal burst damage, spreading a reduced copy outward. `Septic Burst` favors area damage; `Living Culture` preserves spread and Biomass. Capstones make elite rupture leave a capped hazard or transfer its oldest mutation to one new host.
- **Quarantine — area.** Create a boundary that prevents infection transfer across it but greatly amplifies infection progression inside. `Hot Zone` maximizes damage and mutation speed; `Clean Room` contains spread while harvesting Biomass safely. Capstones collapse the zone into a controlled final spread or cure outside infections to empower those within.

#### Ultimate — Pandemic Genesis

Select an infected host. For 12 seconds, its strain becomes the `Prime Strain`: spread attempts do not weaken potency, mutation costs are reduced, and each host may generate only one secondary spread. At the end, all Prime Strain copies revert to legal normal potency. Legendary branches specialize in one perfected mutation or controlled multi-mutation evolution.

#### Pure resonance and safeguards

At five Plaguewright skills, maintaining infection on a required number of distinct natural enemies unlocks one free mutation that does not consume Biomass. Infection generations, cloud counts, husks, and Rabid attacks have global caps. Secondary hosts and created husks cannot recursively generate full Biomass, new husks, or unlimited infection clouds.

The runtime now records distinct natural infected IDs in a fixed 64-entry replay-hashed registry. A five-skill Plaguewright unlocks one `FREE MUTATION` after five distinct hosts have been infected; the token is consumed only when Mutation actually changes at least one host, so an empty target does not waste it. Ordinary mutations still pay their authored Biomass cost.

The current talent runtime also gives `NECROTIC CLOUD` one retained first-spread stack and makes `RABID CLOUD` briefly provoke bounded infighting on newly infected hosts. Mutation behavior is authored in `assets/content/plague_mutations.json`: each strain defines its damage scale, spread radius, hostile splash damage, and Biomass yield, and the catalog is content-fingerprinted for replay compatibility. These effects remain generation-capped and replay-safe. `Clean Room` now emits an explicit replay-safe `BIOMASS PAYOUT` expiry event when its controlled end-of-zone transaction succeeds, giving the UI a clear moment to animate and log the collected Biomass.

Patient Zero’s Necrotic branch is now behavior-specific too: `NECROTIC` increases infection damage, `NECROTIC MASTERY` extends infection duration, and the Spore branch widens natural infection spread. Natural Prime-Strain propagation uses the same one-secondary-spread-per-host cap as Vector Swarm, so Pandemic Genesis cannot bypass the epidemic budget through passive spreading.

#### Plaguewright doctrine choices

- `Carrion Culture`: prioritize corpse economy. Passive collectors seek highest Biomass value, infected remains last longer, and excess processing briefly accelerates Mutation recovery. It does not increase infection damage directly.
- `Living Vectors`: prioritize active spread. Collectors seek the nearest remains and return quickly; successful automatic processing gives the next Vector Swarm cast additional transfer range.
- `Closed System`: prioritize Quarantine. Remains inside Quarantine process automatically without travel, but Biomass produced outside active infection zones is reduced.

All doctrines preserve baseline automatic collection. They change collection priority and how collected Biomass supports the next decision; none requires manual corpse gathering.

### 10.4 Salvager — corpses into temporary machinery

#### Identity and resource

The Salvager starts each wave weak, collects debris as enemies and temporary entities die, then ends the wave with improvised machinery. `Scrap` is granted from eligible natural enemy remains and selected owned objects. Corpses may be represented abstractly, but collection timing and ownership remain visible and deterministic.

The economy must never require the player to already own a Scrap machine or spend an active cast before they can earn the Scrap needed to build something. A Salvager loadout always has automatic collection, a guaranteed opening construction, and a minimum recovery path.

#### Passive Recovery Drone network

- Equipping any Salvager-tagged construction skill grants the class's baseline `Recovery Network`: one passive drone hovers near the tower and automatically collects eligible remains.
- Additional Salvager skills do not each create an unlimited drone. Authored passive contributions add collection range, carrying capacity, speed, or at most one additional drone at class thresholds.
- At three Salvager skills, the network supports two drones. At five Salvager skills, it supports three drones or one heavy collector according to the chosen doctrine. Global caps remain authored data.
- Drones automatically choose claims using deterministic urgency and value rules. Collection continues while every active Salvager skill is cooling down.
- Drones are utility entities. Enemies may destroy them only when a challenge, enemy trait, or doctrine explicitly enables that counterplay. A destroyed baseline drone rebuilds after a visible timer at no Scrap cost so the economy cannot become permanently disabled.
- Active collection effects temporarily accelerate drones already deployed. Doctrine and deterministic claim rules control priorities; active casts never determine whether remains can be collected at all.

#### Bootstrap economy and first-wave safety

- A run with at least three Salvager-tagged skills begins with a `Salvage Cache` of **20 Scrap**. These are provisional tuning values, but the cache must always buy at least one basic Jury-Rigged Turret or one useful Mine Layer cast.
- Recovery Drones collect automatically and cost **0 Scrap**. Drone Overdrive also costs 0; its cooldown controls temporary movement acceleration, not baseline income.
- The first eligible natural enemy killed each wave drops a guaranteed `Starter Bundle` worth **6 Scrap**, even if ordinary yield variance or challenge modifiers would reduce it. The bundle remains long enough for one normal Recovery Drone trip.
- At the start of a wave, if the player has less than **8 available Scrap**, grant a one-time `Field Allowance` that raises available Scrap to 8. This happens once per wave and cannot be triggered by spending, rebuilding, rewinding, restarting, or delaying the wave.
- The normal tower weapon remains fully functional. Salvager skills amplify the run's economy and defenses; choosing the class never removes the tower's ability to kill the first enemies without constructed machinery.
- A zero-Scrap player continues collecting automatically and can cast Drone Overdrive or any authored non-construction utility mode. Every loadout validator must ensure a Salvager-only loadout contains automatic Recovery Network access and at least one useful zero-Scrap active command.
- Losing all temporary machines does not permanently collapse the run. The next Field Allowance plus free collection gives the player a recovery route, though it should remain weaker than preserving an efficient Scrap engine.

These values are not final balance. The invariant is more important: starting cache + guaranteed first bundle must support a meaningful opening build, and the per-wave floor must support recovery without becoming profitable to deliberately waste Scrap.

The current runtime implements the economy-to-machinery slice. Salvager-tagged loadouts receive automatic Recovery Drones and a zero-cost collection network; one- and two-skill loadouts receive a smaller Scrap bootstrap, while three or more receive the documented 20-Scrap opening cache. `Mine Layer` and `Jury-Rigged Turret` spend Scrap directly, `Strip for Parts` converts an eligible temporary building back into capped Scrap, and `Improvised Arsenal` converts the carried Scrap total into a temporary mortar whose strength scales with the amount spent. These operations are authored, deterministic, included in state hashing, and covered by headless tests. The HUD now exposes projected Scrap costs, on-field and reserved remains, and claimed/active drone counts.

The current implementation also wires the Recovery Network speed nodes, Trapwork mine discount, paired Scrap Colony turret behavior, linked-trap presentation and trigger handoff, and replay-hashed `MODULE RECOVERY`: dismantling with the transfer branch primes one handoff, while its capstone primes a stronger handoff, and the next successful Jury-Rigged Turret consumes that module. Further Salvager work is balance stress and additional content, not a missing mandatory collection loop.

The five-skill Salvager resonance is now live: successful Mine Layer, Jury-Rigged Turret, and Improvised Arsenal constructions record three distinct construction categories. Once all three have been used, the next Improvised Arsenal becomes `MASTERWORK READY`; its temporary mortar receives a bounded faster operating cadence, the ready state is consumed, and the category mask/ready flag are replay-hashed. The HUD exposes the ready state beside the Scrap resource instead of applying a global damage increase.

`PERMAFROST CHANNEL` now has its first behavior-specific runtime slice: Trap Foundry placements made with the talent form deterministic nearest-neighbor links. When one linked trap triggers, it immediately primes the other trap's rearm window and emits a `linked_prime` visual event at the receiving trap. Link IDs and prime timers are replay-hashed, and the headless suite verifies reciprocal links plus the trigger handoff. The link is bounded to existing Trap Foundry instances, never creates extra traps, and remains safe when one endpoint expires.

Trap contact handling now follows the authored entry contract: an enemy can trigger a given floor trap once while inside its footprint, even if the trap rearms before that enemy leaves. The contact ID is cleared only after the enemy exits, so a later physical re-entry can trigger the trap again. Contact state is replay-hashed and does not change wall blocking or flying/phase eligibility.


Linked traps now also have a dedicated battlefield presentation: each trap shows its armed/empty charge state, linked endpoints are connected by a restrained line, and a primed endpoint receives a cyan pulse ring. This keeps the link behavior legible without adding permanent high-contrast overlays to unrelated structures.

#### Scrap lifecycle and corpse/remains contract

- On an eligible natural enemy death, create a lightweight `BattlefieldRemain` with stable ID, world position, Scrap value, source enemy type, creation tick, expiry tick, and claim state.
- A remain lasts **10 seconds** by default. Its icon fades during the final 3 seconds. Boss and elite remains may last longer when authored.
- Remains do not block movement, targeting, projectiles, or structure placement. They are simulation objects, not collidable enemy corpses.
- The Recovery Network reserves remains in stable order: earliest expiry, highest value, shortest drone path, then remain ID. A reserved remain shows which drone owns the claim.
- Two drones cannot collect the same remain. If the claiming drone dies or its order becomes invalid, release the claim on the next simulation tick.
- Scrap is awarded when collection completes, not when the drone starts travelling. The HUD separately shows material `ON FIELD` so expected income is visible without pretending it is spendable.
- Uncollected remains expire and grant nothing unless a talent explicitly enables partial automatic recovery.
- Plaguewright, Beastmaster, and Salvager may compete for the same physical remain. A remain has separate authored components such as `biomass_value`, `feed_value`, and `scrap_value`, plus a `consumption_policy`. Default policy is exclusive: the first completed consume/collect action removes it for every class.
- Infection death effects resolve before the remain becomes collectible. A Spore explosion may occur, then leave one ordinary remain; the explosion cannot manufacture extra remains.
- Rebel echoes, Symbiotic husks, free reinforcements, recursively created summons, and temporary copies have zero or sharply capped Scrap value.
- Rewind, Temporal Anchor, resurrection, replay seeking, and boss phase transitions cannot recreate a consumed remain or award its Scrap twice. Consumed remain IDs enter deterministic state/history tracking.
- Keep at most a fixed global number of live remains. At the cap, merge nearby same-tier remains into one value-preserving bundle using stable IDs rather than deleting value or growing the container indefinitely.

#### Wave rhythm and carryover

- Available Scrap persists during a wave and between waves, but carryover into the next wave is capped at **30 Scrap** for the first balance pass.
- Scrap above the carry cap is not converted into permanent currency. During the between-wave screen, the player must spend it on legal preparation, bank it through an authored talent, or lose the excess when the next wave begins.
- Display an explicit countdown and `NEXT WAVE CARRY: 30` warning. Never discard Scrap without showing the amount that will be lost.
- Temporary machines follow their own lifetime rules. The class should become powerful late in a wave because it has both accumulated Scrap and active machinery, then return to a manageable preparation state rather than snowballing infinitely across ten waves.
- Endless mode may increase carry cap slowly through authored milestones, but income and machine costs must scale together.

#### Scrap HUD and interaction contract

Place the Salvager resource widget immediately above or beside the five-skill bar when Salvager is the dominant class. It must not overlap cooldowns, targeting text, tower health, or the ultimate slot.

The widget shows four different quantities:

```text
SCRAP  22          spendable now
ON FIELD  9        uncollected remains
RESERVED  4        spendable Scrap committed by the current placement preview
CARRY  22 / 30     amount retained when the next wave begins
DRONES  2 / 2      RECOVERY FLEET // 5 SCRAP IN TRANSIT
```

- `SCRAP` is the large primary number. Animate increases from the collected remain toward this counter.
- `ON FIELD` is smaller and uses a hollow icon because it is not spendable. Hover/focus explains the nearest expiry and current drone claims.
- `RESERVED` appears only while targeting a variable-cost construction. The main number previews the post-cast amount, for example `22 → 8`.
- `CARRY` appears persistently during between-wave preparation and only as a warning during combat when above the cap.
- `DRONES` shows active/rebuilding collectors, doctrine priority, and carried-but-not-yet-delivered Scrap. In-transit Scrap remains part of `ON FIELD` until delivery and is never counted twice.
- Every Scrap-spending skill icon shows its minimum cost in the lower corner. Affordable skills use the normal frame; unaffordable skills are dimmed and state `NEED 6 MORE SCRAP` on hover/focus.
- Variable-cost skills use discrete spending bands, not a pixel-sensitive free slider. Example: `24 / 40 / 60 Scrap` for light, heavy, and colossal Improvised Arsenal. Keyboard/controller can cycle bands before confirming placement.
- The world shows remains as small readable metal silhouettes with value pips. High-value remains have a stronger outline, not merely a different color.
- Collector drones draw a thin claim line only while the relevant skill or Scrap widget is focused. Constant lines would make busy waves unreadable.
- A construction preview shows cost, post-cast Scrap, machine tier, expected lifetime, salvage return, and whether spending would drop below the next known preparation threshold.
- The between-wave panel summarizes `generated`, `collected`, `expired`, `spent`, `recovered`, and `carry lost`, helping players understand why their economy succeeded or failed.
- Reduced-motion mode replaces flying Scrap particles with a brief counter flash and world-icon collapse.
- Tooltips use exact terms: `COLLECTED` means spendable, `ON FIELD` means unclaimed or in transit, and `RECOVERED` means returned by dismantling.

#### Skills

- **Drone Overdrive — no target; passive network plus active boost.** **Equipped passive:** improve the Recovery Network with one additional collector capacity tier and longer claim range. **Active:** snapshot every currently deployed Recovery Drone and increase its movement speed by 100% for 6 seconds. It does not spawn, rebuild, teleport, retarget, or add drones. Drones rebuilt or deployed after activation do not receive that cast's boost. `Turbo Fleet` extends boost duration and reduces turnaround time after delivery; its capstone `CHAINED THRUSTERS` gives a returning boosted drone one shorter second boost after it picks up its next claimed remain. `Loaded Afterburners` gives a larger speed bonus only while carrying Scrap; its capstone `HOT DELIVERY` briefly improves the Recovery Network's delivery handoff after a high-value bundle arrives. Both branches improve timing, not Scrap yield.
- **Jury-Rigged Turret — placement.** Spend a chosen amount of Scrap to build a disposable tower whose health, duration, and weapon scale in bands. `Rotary Heap` is cheap rapid fire; `Cobbled Cannon` is slower area damage. Capstones let the turret consume nearby debris for repairs or eject part of its Scrap on destruction.
- **Mine Layer — path placement.** Convert Scrap into a short line of low-cost mines. `Shrapnel Bed` deals physical area damage; `Chemical Canisters` applies Burn/Slow with reaction-compatible tags where legal. Capstones recycle untriggered mines or chain one controlled detonation.
- **Strip for Parts — owned structure/summon target.** Destroy or dismantle an eligible temporary object and recover a percentage of its remaining material value. `Careful Disassembly` is efficient but channeled; `Emergency Strip` is instant and grants less Scrap. Capstones transfer one compatible module to the next construction.
- **Improvised Arsenal — placement/area.** Spend all selected Scrap to create a machine chosen by spending thresholds: barricade gun, rocket cart, magnetic crusher, or heavy platform. `Modular Arsenal` lets the player choose from two valid machines; `Magnificent Junk` automatically builds the highest tier with a volatile drawback. Capstones add one temporary module based on the most common debris source.

#### Ultimate — Everything Is Ammunition

For 10 seconds, natural enemy deaths, expired summons, destroyed structures, consumed traps, and eligible projectiles generate reduced Scrap. Each source category has its own cap. Free objects created during the ultimate cannot return more Scrap than their original paid value. Legendary branches emphasize a construction frenzy or one enormous final arsenal.

#### Pure resonance and safeguards

At five Salvager skills, spending Scrap in three different construction categories grants `Masterwork`, improving the next improvised object's behavior rather than raw global damage. Every entity carries an immutable salvage origin/value; conversion efficiency is always below 100%; no dismantle/build loop may increase total material.

#### Salvager doctrine choices

- `Recovery Fleet`: use the maximum legal number of quick drones. They prioritize soon-to-expire remains and keep `ON FIELD` low. Best for constant spending and many cheap machines.
- `Heavy Lifter`: use fewer slower collectors with large carrying capacity. They prioritize high-value remains and can transport bundled Scrap efficiently. Best for saving toward Improvised Arsenal.
- `Local Reclamation`: structures and traps passively collect a small radius around themselves, while tower drones focus on distant remains. Each remain is still claimed once. Best for spread-out defensive layouts.

Doctrine selection changes automation strategy, not whether collection exists. The HUD shows the chosen priority, while Drone Overdrive changes only movement speed for drones that are currently deployed.

### 10.5 Beastmaster — a few persistent evolving companions

#### Identity and resource

The Beastmaster is the emotional opposite of Legion Commander. Equipping any Beastmaster-tagged skill automatically creates exactly one named bonded pet at run start; the player never has to spend an active cast just to unlock the class. There is no separate permanent-pet summon skill in the baseline kit. Additional Beastmaster skills improve the pet's basic attack damage and may add traits, commands, or survival tools. `Bond` is tracked through survival, commands followed, feeding, damage prevented, and elite participation. Losing the pet should hurt, but must not permanently ruin the profile or demand save scumming. Future content may unlock a tightly capped second or third pet, but the baseline class is one valuable companion rather than an army.

#### Skills

- **Pounce — world-point/area.** The bonded pet leaps from anywhere in the arena to the chosen point and damages enemies in the landing radius using a multiplier of the pet's basic attack damage. It is the replacement for the former pet-summon slot: a command, not a summon. Its talents change landing control, target priority, or recovery. `Pack Takedown` briefly coordinates future basic attacks; `Apex Pounce` empowers one high-Bond landing. Capstones pin an elite briefly or cause a successful interrupt to grant Bond.
- **Feed — corpse target/area.** A beast consumes one eligible corpse to heal and gain temporary growth. `Carrion Feeder` supports frequent small meals; `Trophy Feast` reserves elite corpses for permanent run traits. Capstones cleanse one debuff or share part of healing with the pack. The runtime now creates value-one Beastmaster remains from natural enemy deaths, so Feed has a passive corpse supply without requiring Salvager or Plaguewright.
- **Adaptation — choose contextual trait.** Temporarily grant beasts an adaptation based on observed threats: Armored Hide, Lightning Glands, Regeneration, Burrowing, or Spiked Carapace. `Instinctive` chooses the best deterministic counter automatically; `Selective Breeding` lets the player choose from valid options. The selected adaptation and expiry are replay-hashed; capstones make a repeatedly used adaptation evolve for the rest of the run within a trait cap.
- **Pack Call — area.** Regroup beasts, cancel unsafe pursuits, and grant a formation buff. `Defensive Circle` protects the tower/allies; `Hunting Formation` surrounds a priority target. Capstones share Bond-generated bonuses briefly or rescue one downed beast to the rally point. Pack Call never creates a second permanent pet.
- **Hunt Command — enemy target.** Assign the bonded pet a visible priority target from anywhere in the arena. The pet pursues that target and gains a bounded basic-attack bonus for the command window; it does not change skill damage or summon another pet. `Lone Prey` rewards isolation, `Guardian Hunt` lets the pet intercept pressure, and the capstone briefly pins the first marked elite hit.

#### Ultimate — Apex Evolution

Transform the highest-Bond living beast for 12 seconds into a boss-scale form that combines its earned traits, gains crowd-control resistance, and receives enhanced commands. Ties resolve by stable beast ID unless the player selects one. Afterward it returns to its previous legal health percentage and retains no temporary maximum-health exploit. Legendary branches create one colossal apex or synchronize a lesser evolution across the pack.

#### Pure resonance and safeguards

At five Beastmaster skills, the pet gains one `Signature Trait` after surviving a wave with meaningful participation, and each additional Beastmaster skill's passive contribution is shown as a basic-damage increase rather than a skill-damage increase. Traits are deterministic choices from valid weighted options and are previewed before selection. The pet ID, name, traits, Bond, health, and downed state persist only for the run unless a future explicit stable system is designed. Summon caps and body-blocking rules still apply.

The first Signature Trait transaction is now live: a five-Beastmaster loadout records bounded pet attack participation, awards one seed-and-wave-selected trait when the pet survives a cleared wave, emits a replay-visible trait event, applies the trait to basic pet behavior (defense, damage, regeneration, speed, or spiked damage), and exposes the result in the contextual HUD. The trait is run-scoped and included in the state hash; it is not a profile-persistent breeding system. The baseline contract is now explicit in content as well: equipping any Beastmaster-tagged skill creates exactly one pet, while the `BONDED INSTINCT` tree node improves that pet's basic attack and does not unlock or summon a second pet.

The bonded pet now has an explicit bounded failure state when `PACK TAKEDOWN` is equipped. Lethal enemy contact places the pet in a five-second replay-hashed downed window instead of immediately deleting it; the next Pack Call can rescue it at the rally point with 35% health, clear its temporary injury, and preserve its stable run ID. If the window expires, the pet is removed as normal. This rescue is separate from Rally Beacon's ordinary-summon `FIELD REVIVE` path and does not create a replacement pet.

The `ALPHA'S FEAST` talent now has a behavior-specific handoff: feeding on an eligible remain arms one replay-hashed empowered Pounce, which consumes the charge on the next landing and increases only that landing's area damage. It expires safely if unused and does not change the pet's basic attack damage, preserving the Beastmaster distinction between pet attacks and command skills.

`TROPHY FEAST` now has its authored runtime branch as well. Feeding on a remain whose source is a non-basic enemy type (for example a Tank, Shielded, or Teleporter) grants a bounded eight-second `1.15x` basic-attack growth effect and a small additional Bond payout. Ordinary Grunt, Runner, and Swarmling remains do not trigger the trophy branch. This growth uses the pet's ordinary attack scale, never the Pounce payload, and it expires through the normal allied buff timer.

`LIGHTNING GLANDS` now has its authored basic-attack behavior: while the lightning adaptation is active, each ordinary pet hit applies at most one second of Shock and emits a distinct `lightning_glands` event. The effect is attached to the pet attack path rather than Pounce, so it cannot be amplified by command damage or create uncapped status uptime.

`SELECTIVE BREEDING` now tracks the chosen adaptation's replay-hashed streak. Choosing the same adaptation again while the capstone's prior trait is active makes it persistent for the remainder of the run; choosing a different adaptation resets the streak and persistence. Persistent adaptations reapply their authored defense, damage, regeneration, speed, or Lightning Glands behavior through the normal pet update path rather than relying on a permanent buff-stat mutation.

`FEED` now has a concrete `CLEANSE` target: an enemy hit places a bounded two-second injury state on the bonded pet, reducing its ordinary attack damage and movement speed. Feeding with `CLEANSE` equipped removes that injury immediately. The injury timer is included in the allied-unit replay hash and does not alter Pounce's separate command payload.

### 10.6 Artillerist — prediction and long-range bombardment

#### Identity and resource

The Artillerist aims where enemies **will be**, using long delays, huge areas, and predicted path positions. `Targeting Data` is earned when delayed attacks land near their predicted center or hit the declared target count. Missing loses the opportunity but should not remove already earned Data unless a risky talent says so.

#### Skills

- **Spotter Drone — world point/area.** Reveal deterministic enemy position projections at several future ticks and improve bombardment previews. `Forward Observer` tracks moving elites; `Survey Grid` covers a broad route section. Capstones expose route changes after walls/portals or mark one perfect-impact window.
- **Mortar Barrage — area.** After a visible delay, fire several shells into a circle. `Tight Grouping` concentrates boss damage; `Saturation Fire` covers a larger area with lower precision. Capstones correct the final shell toward surviving targets or leave a capped hazard.
- **Rail Cannon — direction/line.** Charge an enormous line shot that pierces all enemies at resolution time. `Siege Rail` gains structure/armor penetration; `Snapshot Beam` has less damage but shorter forecast horizon. Capstones reward striking one isolated elite or a long ordered line of enemies.
- **Cluster Shell — area.** Launch one slow shell that breaks into seeded submunitions over the previewed footprint. `Airburst Pattern` spreads evenly; `Hunter Submunitions` bias toward projected enemy cells with reduced payload. Capstones reserve one bomblet for a marked elite or create reaction-compatible elemental payloads.
- **Walking Barrage — draw direction or two points.** Schedule explosions that march across the field over several seconds. `Rolling Curtain` controls a broad wave; `Chasing Salvo` adjusts later impacts using newly earned Data. Capstones reverse the line once or synchronize with allied structure fire.

#### Ultimate — Orbital Fire Mission

The player places up to three valid waypoints. An orbital barrage traces the polyline with clearly timed impacts. More Targeting Data improves timing density and prediction visualization, not unbounded damage. Input is quantized and recorded in the replay. Legendary branches favor a precise anti-elite beam path or a wide saturation corridor.

#### Pure resonance and safeguards

At five Artillerist skills, three consecutive accurate impacts grant `Fire Solution`: the next delayed skill previews one enemy-route response and slightly corrects its final impact. Prediction uses actual deterministic path intent and known movement effects, never hidden future RNG. Every impact point and timing is fixed at cast or at an explicitly recorded correction tick. The first behavior-specific talents are now live: `Forward Observer` extends the forecast horizon, `Survey Grid` widens the observation footprint, `Perfect Impact` improves the data payout, `Charged Rail` spends eight visible Targeting Data for a stronger shot, `Fast Fuse` shortens Cluster Shell arming, and the Cluster capstone adds a reduced second impact zone.

The runtime now tracks three consecutive accurate predicted Mortar impacts for five-skill Artillerist loadouts. The third hit arms one replay-hashed `Fire Solution`; the next delayed Mortar corrects its recorded impact point toward the target’s current legal position, consumes the token, and emits a preview event. A miss resets the consecutive counter, and the HUD exposes both progress and readiness.

Walking Barrage’s authored branches now also resolve behaviorally: `LONG MARCH` extends the deterministic route, `DENSE SALVO` packs impacts into a tighter/higher-density path, and `ORBITAL FIRE MISSION` adds one replay-safe orbital strike at the end of the march. The capstone is bounded to one strike per zone and is included in the normal skill-zone hash/state lifecycle.

### 10.7 Void Shepherd — teleportation and spatial control

#### Identity and resource

The Void Shepherd changes **where** enemies and routes exist without constructing walls. `Instability` rises with displacement distance, number of entities moved, portal reuse, and banishment duration. Higher thresholds produce deterministic tradeoffs such as shorter portal lifetime, self-damage to rifts, or hostile void echoes—not random teleport destinations.

#### Skills

- **Rift Gate — one placement target with a deterministic exit.** Place the entrance; the first implementation computes a legal exit along the route at a bounded offset, draws both portal footprints and their connector, and transfers each eligible enemy once per portal cooldown while preserving path progress rules. `Stable Transit` is predictable and limited; `Hungry Gate` damages and debuffs travellers while raising Instability. Later capstones can expose an explicit second placement target, add one-way routing, or add a third gate with explicit connection order.
- **Spatial Collapse — area and destination.** Pull/teleport nearby enemies toward a chosen point. `Compression` groups tightly for area damage; `Scatterfold` distributes enemies among seeded legal points. Capstones preserve elemental states through collapse or deal collision damage with strict caps.
- **Banish — enemy target.** Remove one non-boss enemy from active play for several seconds, then return it at a previewed legal point. `Long Exile` emphasizes control; `Void Sentence` damages on return. Capstones banish a small group briefly or make a boss untargetable but delayed for a much shorter resistant duration.
- **Phase Exchange — two areas.** Swap eligible enemy groups while preserving each entity's identity, health, and state. `Tactical Exchange` uses small precise circles; `Mass Transposition` swaps more normals with high Instability. Capstones exchange projectiles/status zones under explicit compatibility rules or leave temporary rift scars.
- **Event Horizon — area.** Enemies crossing its boundary are displaced backward once and marked against immediate retrigger. `Receding Edge` maximizes backward route displacement; `Orbiting Edge` rotates enemies around the zone for grouping. Capstones reverse direction on expiry or feed moved enemies into an existing Rift Gate.

#### Ultimate — Impossible Geometry

For 10 seconds, up to four authored rift nodes form a visible directed portal network. Enemies traverse according to numbered connections and per-entity portal cooldowns. The network may create strange routes but must always have a deterministic exit and maximum traversal count. Legendary branches favor a controllable routing puzzle or a damaging unstable network.

#### Pure resonance and safeguards

At five Void Shepherd skills, three different spatial operations grant `Fixed Point`, allowing the next manipulation to ignore one Instability penalty. Position validation, legal return cells, path progress, portal cooldowns, traversal counts, and fallback exits enter state hashing. Teleport effects cannot duplicate on-entry traps, rewards, projectiles, or reaction events.

The runtime now tracks the distinct Rift Gate, Spatial Collapse, Banish, Phase Exchange, and Event Horizon operations in a replay-hashed mask. Three distinct operations arm one `FIXED POINT`; the next spatial operation suppresses exactly one authored Instability increase and emits a visual event. The HUD exposes the pending token and the operation state remains bounded.

### 10.8 Oathkeeper — defensive vows and clean execution

#### Identity and resource

The Oathkeeper gains `Resolve` by accepting and completing temporary defensive vows. Vows are generated only from currently achievable conditions and are shown before acceptance: prevent tower damage, keep an ally alive, stop an enemy crossing a line, interrupt an elite, or protect a structure. Failure gives no Resolve and a short lockout, not permanent punishment.

#### Skills

- **Guardian Ward — ally/structure/area.** Apply a shield with a visible damage budget. `Single Bulwark` strongly protects one target; `Shared Aegis` divides protection across several. Capstones retaliate after the ward absorbs its full budget or preserve a small shield on vow completion.
- **Intercept — world point/ally.** Summon a defender that redirects eligible attacks and projectiles. `Faithful Guardian` follows one target; `Shield Line` guards an area. Capstones survive one lethal interception or convert prevented damage into Resolve under a cap.
- **Challenge — enemy and allied target.** Force an elite to prioritize a chosen defender for a limited duration. `Honorable Duel` empowers both sides and increases vow reward; `Condemnation` weakens the challenged enemy when it attacks anyone else. Bosses use threat weighting rather than absolute control.
- **Sanctuary — area.** Create defensive ground that heals lightly, grants resistance, and defines a protectable boundary. `Hallowed Ground` protects summons/tower; `Last Refuge` becomes stronger as tower health falls. Capstones cleanse one status or lock in a vow line enemies must not cross.
- **Judgment — enemy/area.** Spend Resolve for retaliatory damage scaling with recently prevented damage and completed vows. `Measured Justice` spends fixed Resolve efficiently; `Final Verdict` spends all Resolve for elite execution pressure. Capstones repeat a reduced strike after a flawless vow or shield allies from the judged target.

#### Ultimate — Unbroken Oath

For 10 seconds, Resolve cannot decrease below its activation amount. Completing a vow triggers a free reduced Judgment and immediately offers one valid short vow. Failed vows during the ultimate end their chain but do not erase existing Resolve. Legendary branches emphasize tower protection or aggressive elite challenges.

#### Pure resonance and safeguards

At five Oathkeeper skills, completing three different vow types grants `Exemplar`, making the next accepted vow offer two reward choices. Vow generation uses deterministic valid-candidate filtering; impossible or already-failed conditions are never offered; self-created harmless loops cannot generate Resolve repeatedly.

### 10.9 Fatebinder — deterministic controlled uncertainty

#### Identity and resource

The Fatebinder exposes and manipulates a dedicated deterministic event stream. It may look unpredictable, but identical seed, content, and input always produce identical outcomes. `Fate` is banked by accepting unfavorable visible outcomes or completing risky predictions, then spent to improve or reorder future events.

Never use the global combat RNG implicitly. Fate events use named substreams, stable sequence numbers, and preview-safe outcomes so viewing a result does not consume or change it.

#### Skills

- **Loaded Dice — self buff.** The next three eligible proc checks use the better of two already scheduled deterministic rolls. `Steady Hand` affects more modest checks; `High Roller` affects one major check. Capstones bank the unused lower roll as Fate or apply one roll to a selected ally skill.
- **Misfortune — enemy target.** Replace the enemy's next eligible special outcome with a seeded disadvantage: longer telegraph, failed shield, exposed flank, or weaker summon. `Hexed Elite` targets one dangerous ability; `Bad Omen` spreads minor misfortune across a group. Boss substitutions come from phase-safe tables.
- **Lucky Shot — enemy/area.** Deal visibly variable but bounded seeded damage. Before confirmation, show the possible range; talents may reveal the exact result. `Reliable Fortune` narrows variance and improves floor; `Jackpot` widens variance and rewards spending Fate. Capstones ricochet a high roll or convert a low roll into utility.
- **Stack the Deck — no target/UI sequence.** Preview the next several Fate events and swap two legal positions. It changes only the Fate substream, not enemy spawn or unrelated combat RNG. `Deep Read` previews farther; `Quick Cut` has a shorter cooldown and smaller queue. Capstones lock one event or discard one event at a Fate cost.
- **Double or Nothing — target another skill before cast.** Spend Fate to schedule two deterministic outcomes: doubled effect or partial loss of cooldown/resource investment. The exact odds and consequences are shown. `Hedged Bet` reduces both reward and loss; `All In` offers a major double with meaningful debt. #### Ultimate — House Always Wins

For 12 seconds, unfavorable eligible Fate outcomes are banked as `House Edge`. After a stated number of failures, the next eligible event becomes a guaranteed authored favorable result, consuming House Edge. The guarantee is visible and cannot be spent on invalid event types. Legendary branches favor frequent modest corrections or one spectacular guaranteed jackpot.

### 12.3 Resource transactions

Resolve casts in a fixed order:

```text
validate target
-> calculate and preview costs
-> reserve resource/health/charge
-> snapshot scaling values
-> execute effects
-> consume or refund according to authored rule
-> start cooldown
-> emit replay and presentation events
```

This order prevents double consumption, buffs changing halfway through one damage event, and replay disagreement. A cast that fails validation spends nothing. Once a valid cast executes, its resource snapshot is fixed even if another effect changes the resource during the same tick.

### 12.4 Profiles and replays

- Version the profile schema before storing synergy presets, new skill IDs, or purchased nodes.
- Preserve old five-skill loadouts through an explicit migration table.
- Replays store stable IDs, target data, cast sequence, and content fingerprint. Resource generation remains deterministic simulation output, not separately recorded unless it results from player input.
- Add allegiance, class resource, structure topology revision, health costs, and sacrifice results to state hashing.

## 14. Balance guardrails

- A complete class loop should outperform five unrelated skills when executed correctly, but require more decisions, setup, risk, or positioning.
- No class should solve every wave shape. Arcanist is cooldown/input limited; Legion is vulnerable to area damage and caps; Bloodbinder risks tower death; Usurper is weaker against bosses and isolated targets; Architect needs setup time and can lose structures; Stormcaller loses efficiency against scattered, state-resistant, or rapidly replaced enemies and punishes incorrect spell order.
- Keep the base tower weapon relevant. Skills create burst windows, control, bodies, or routes; they should not provide permanent effortless damage exceeding a specialized tower loadout.
- Class resources reset at run start. Decide per resource whether it persists between waves; default to reset or decay to prevent preloading ten stacks before every encounter.
- Summons and rebel echoes created by triggered effects cannot recursively generate the trigger that created them.
- Boss control converts into authored alternatives instead of immunity with no feedback.
- Health sacrifice must never be an invisible mandatory optimum. Show cost, recovery route, and danger clearly.
- Wall mazes need structure caps, build costs, minimum path-width rules, and enemy counters so they add strategy without allowing permanent stalls.
- Reaction chains need event budgets, generation-depth limits, state-consumption rules, and per-target cooldowns. Perfect Storm may remove state consumption temporarily but never these safety limits.
- Expansion resources require conservation rules: rewinds cannot duplicate value, bounties cannot reward stalling forever, infections cannot recurse without caps, Scrap loops return less than they cost, beast traits have limits, predicted fire cannot auto-correct every miss, portals have traversal caps, vows reject self-made exploits, and Fate preview never changes the stream.

## 17. Definition of done

This redesign is complete when:

- Five equipped skills produce a clear, explained class identity without a separate class lock.
- The six core classes and nine expansion classes each have at least five designed skills, two meaningful specialization directions per skill, one themed manual ultimate, a pure resonance rule, and explicit counterplay.
- Pure and mixed loadouts both work, with interactions driven by authored tags and resources.
- Resource, summon, sacrifice, allegiance, and structure systems are deterministic, replay-safe, content-validated, and observable in headless telemetry.
- The HUD communicates resource generation, consumption, health costs, allegiance, placement legality, and cooldowns without overlapping text.
- Every class has a measurable strength, execution demand, and weakness.
- The original weapon, upgrade, Daily, profile, replay, UI-layout, content, and headless simulation checks continue to pass.
